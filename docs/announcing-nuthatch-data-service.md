# Nuthatch Data Service is live on Arbitrum One

Nuthatch Data Service is a Horizon proxy service for reproducible Nuthatch nests.
The first self-run beta serves the Horizon activity nest in NAMED mode at
`https://nuthatchds.89.167.109.4.sslip.io`, NID
`36d3c71446a56cdb5b90536d3f5f77351b1d92efcca94bc2fd41b1c368e69410`.

The service sells an exact `(NID, query mode, endpoint)` offering, not a vague
promise of SQL. The public gateway exposes only the author-sanctioned named
queries for the first nest. Arbitrary SQL is refused both by the gateway and by
the Nuthatch query allowlist.

## Mainnet proof

The UUPS service provision floor was migrated from 555 GRT to zero in
[this upgrade](https://arbiscan.io/tx/0xdb512643b0eb2f73cbfa4d86d1307abc125739d8e6c007a512c0b89f5291d3b5).
Horizon Staking still requires a non-zero provision, so the beta provider uses
0.0001 GRT.

A bounded payment proof then completed on Arbitrum One. A 0.000004 GRT
EIP-712 TAP receipt passed through the public gateway and returned a real
Nuthatch query response with HTTP 200. Replaying that identical receipt
returned 402. A signed RAV for the accepted receipt was redeemed through
[`NuthatchDataService.collect()`](https://arbiscan.io/tx/0x9138d9bd8f5937162f87261b8e6853f692e1a76f6bcd0f497defb50c5f680c05).
Afterwards the payment escrow balance was zero and GraphTally collection events
were present in the receipt.

## Checks

Six Rust gateway tests and seventeen Solidity tests passed, including UUPS
storage preservation during the provision-floor migration. Formatting, builds,
and Compose validation passed too. On the VPS we checked public TLS discovery,
missing-receipt rejection (402), wrong-NID rejection (404), SQL refusal in
NAMED mode (404), and rate limiting (429). The isolated service uses Nuthatch
2.5.0, which reproduces the advertised NID.

The gateway is deliberately narrow: Nuthatch, Postgres, and the gateway listener
are loopback-only; Caddy is the sole public entrypoint; request bodies are
limited to 16 KiB; NID routes are limited to 10 requests a second with a burst
of 20. The idle gateway was measured at 3.6 MiB RSS with a 512 MiB systemd cap.

## Beta boundary

Paid access is presently limited to an allowlisted, GraphTally-authorized test
signer. The RAV in the proof was generated by that test client. Automatic RAV
aggregation and collection are intentionally disabled until a separate
aggregator and consumer signer-onboarding flow are deployed and tested. The
public discovery API is live; this is not yet an unrestricted paid API.
